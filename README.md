# Penetration Testing Lab

This repository documents my hands-on penetration testing and red team lab work. It serves as a portfolio of practical experience with network enumeration, Active Directory attacks, credential attacks, exploitation, privilege escalation, lateral movement, and post-exploitation techniques.

## Purpose

The goal of this lab is to develop and demonstrate practical offensive security skills in controlled environments while documenting the methodology, tools, findings, and remediation techniques associated with each attack.

## Lab Areas

- Active Directory penetration testing
- Network enumeration and service discovery
- Credential attacks
- Privilege escalation
- Lateral movement
- Post-exploitation
- Web application testing
- Vulnerability identification and validation
- Penetration testing reporting

## Tools

Tools used throughout the lab include:

- Nmap
- BloodHound
- Responder
- Impacket
- Kerbrute
- NetExec / CrackMapExec
- Mimikatz
- Evil-WinRM
- Hashcat
- Hydra
- ffuf
- Gobuster
- SQLMap
- PingCastle

Additional tools will be documented as they are incorporated into the lab.

## Disclaimer

All techniques documented in this repository are performed in controlled lab environments or against systems for which I have explicit authorization. The material is intended for educational and professional development purposes.
