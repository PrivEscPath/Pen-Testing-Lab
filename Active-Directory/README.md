# Active Directory Penetration Testing

This section documents hands-on Active Directory penetration testing techniques performed within controlled lab environments.

The objective is to develop an understanding of common Active Directory attack paths, how they can be identified and exploited during a penetration test, and how organizations can detect or mitigate these weaknesses.

## Topics

This section will include practical exercises covering:

- Active Directory enumeration
- User, group, and computer discovery
- SMB and LDAP enumeration
- Kerberos enumeration and attacks
- Password and credential attacks
- LLMNR/NBT-NS poisoning
- NTLM authentication attacks
- Active Directory Certificate Services (AD CS)
- BloodHound attack-path analysis
- Credential dumping
- Lateral movement
- Privilege escalation
- Domain privilege escalation
- Post-exploitation
- Detection and remediation

## Tools

Tools used throughout these exercises may include:

- Nmap
- BloodHound
- NetExec / CrackMapExec
- Impacket
- Responder
- Kerbrute
- Mimikatz
- Evil-WinRM
- Hashcat
- PingCastle

Additional tools will be added as the lab develops.

## Lab Environment

Exercises documented in this section are performed against intentionally configured systems in a controlled lab environment.

Detailed network diagrams, system configurations, attack paths, and individual exercises will be added as the environment develops.
